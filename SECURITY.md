# Signalement de vulnérabilités

Ne publiez pas de détails exploitables, d'identifiants, de données personnelles ou de journaux contenant des secrets dans les issues publiques.

Utilisez le signalement privé de vulnérabilité GitHub si cette option est disponible dans l'onglet Security du dépôt. Sinon, contactez l'équipe Convaincre par les canaux de contact indiqués sur [convainc.re](https://convainc.re/).

Indiquez la version du plugin, l'environnement, les conditions de reproduction avec des données fictives, le périmètre et les conséquences possibles. Ne réalisez aucun test intrusif sur un site tiers sans autorisation.

Le plugin ne requiert pas de compte Convaincre pour la création de site. Les fonctionnalités connectées traitent potentiellement des données sensibles : toute modification doit préserver les contrôles d'accès, la validation, le consentement et la protection des secrets.
